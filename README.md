# 🔐 Password Generator

A simple, interactive **Password Generator** built using **HTML, CSS, and JavaScript**. It allows users to generate strong and secure passwords with customizable lengths.

## 🧰 Technologies Used

- **HTML5** – Structure and UI elements
- **CSS3** – Styling and layout
- **JavaScript** – Logic for generating passwords

## 🚀 Features

- Generate passwords of customizable length (4 to 32 characters)
- Includes lowercase, uppercase, numbers, and special symbols
- Clean and responsive user interface
- No backend — fully client-side and works offline
